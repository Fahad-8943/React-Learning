what is react 

- React is a library that helps develpers build fast and interactive user interface using re-usable componets
- React app is a collection of different libraries.
- Componets : re-usable piece of user interface. file name should be in PascalCase. and file extension should be .jsx or .js.
- components are arranged in a tree like structure 
- there will be a root component in react app which commonly known as 'App' component.
- react used to create single page web application (sPa) : loads one html page and dynamically updates the content as user interacts with the app.without reloading the entire page. 
- virtual DOM : virtula (memory) representation of the real DOM. React uses to upadte only the changed parts of the DOM instead of reloading the entire page.
    -setps 
        - initial Render 
            react creates virtual DOM and compares it with the real DOM and updates the real DOM with the changes.
        - state changes 
            when state of a component changes, react creates a new virtual DOM and compares it with the previous virtual DOM and updates the real DOM with the changes.
        - comparison(diffing) 
            compare the new virtual DOM with the previous virtual DOM and updates the real DOM with the changes.
        - react updates only the changed parts of the DOM instead of reloading the entire page.

    -diffing is porcess of comparing the new virtual DOM with the previous virtual DOM and updating the real DOM with the changes.
    -reaconciliation is the process of updating the real DOM with the changes.

-JSX : JavaScript XML is a syntax extension for JavaScript that allows you to write HTML-like code in your JavaScript files. It is used in React to describe the structure of the user interface.

    without JSX : 
        const element = React.createElement('h1', {className: 'fw-bold'}, 'Hello, world!');

    with JSX :
        const element = <h1 className='fw-bold'>Hello, world!</h1>;

-rules for using JSX :
    - every JSX element must be wrapped in a single parent element.
    - parent tag can be any container tag like <div>, <section>, <article>, <main>, <header>, <footer> etc. or a React fragment <> </>.
    - react fragment lets you group a list of children without adding extra nodes to the DOM element.Frgments helps you to avoid adding unnecessary extra <div> wrappers.
    - JSX must have only one parent element.
    - every JSX element must have a closing tag.
    - instead of class attribute, use className attribute in JSX.
    - jsx using camelCase for event handlers instead of lowercase.
    - to provide js inside JSX, use curly braces {}.
    - JSX can contain expressions inside curly braces {}.
    - JSX can contain comments inside curly braces {}.

    babel : JavaScript compiler that converts modern JavaScript code into backward compatible version of JavaScript that can run in older browsers. It is used in React to convert JSX code into JavaScript code that can be understood by the browser.
    component : part of UI

    react Events bindings : 
        -onClick : event handler for click event
        -onChange : event handler for change event
        -onSubmit : event handler for submit event
        -onMouseEnter : event handler for mouse enter event
        -onMouseLeave : event handler for mouse leave event
        -onKeyDown : event handler for key down event
        -onKeyUp : event handler for key up event

        function wihtout argument : 
            const handleClick = () => {
                console.log('Button clicked');
            }
            <button onClick={handleClick}>Click me</button>
        function with argument :
            const handleClick = (event) => {
                console.log('Button clicked', event);
            }
            <button onClick={(event) => handleClick(event)}>Click me</button>

        function with argument as event : 
            const handleClick = (e) => {
                console.log('Button clicked', e);
            }
            < input type="text" onChange={(e) => handleClick(e)} />

React Hooks : 
    -useState : hook that allows you to add state to functional components. it returns an array with two elements, the current state value and a function to update the state value.
        -syntax : const [state, setState] = useState(initialState);
        -initialState : initial value of the state.
        -state : current value of the state.
        -setState : function to update the state value.

    -useEffect : hook that allows you to perform side effects in functional components. it takes two arguments, a function to perform the side effect and an array of dependencies. the function is called after the component is rendered and whenever the dependencies change.
        -syntax : useEffect(() => {
                //code to execute
             }, [dependencies]);
        -dependencies : array of values that the effect depends on. if any of the values in the array change, the effect will be re-run.
            -no dependency : whenever the component is re-renders, the code inside useEffect runs
            -[]            : run this effect only after the initial render 
            -[data]        : run this effect when the data changes


    react rounter dom library that allows you to handle routing in a react application. it allows you to create single page applications with multiple views and navigation between them without reloading the entire page.
        -install react router dom : npm install react-router-dom
        -import BrowserRouter, Routes, Route from react-router-dom
        -BrowserRouter : component that wraps the entire application and provides routing functionality.
        -Routes : component that contains all the routes for the application.
        -Route : component that defines a route for the application. it takes two props, path and element. path is the URL path for the route and element is the component to render when the route is matched.
            -syntax : <Route path="/path" element={<Component />} />

state management : 
    -state : is a JavaScript object that holds data that can change over time. it is used to manage the data and behavior of a component. state is mutable and can be changed using the setState function.
    -props : are read-only and cannot be modified by the child component. props are passed as an object to the child component.
    -lifting state up : is a technique in React where you move the state from a child component to a parent component so that it can be shared between multiple child components. this allows for better state management and avoids prop drilling.

axios : is a promise-based HTTP client for JavaScript that allows you to make HTTP requests from the browser or Node.js. it is used to communicate with APIs and retrieve data from a server. it supports all modern browsers and can be used in both front-end and back-end applications.
    -install axios : npm install axios
    -import axios from 'axios';
    -syntax : 
        axios.get('url')
            .then(response => {
                // handle success
            })
            .catch(error => {
                // handle error
            });

axios instance : is a way to create a pre-configured instance of axios with default settings. it allows you to set default headers, base URL, and other configurations that will be applied to all requests made using that instance. it is useful for creating a centralized configuration for your API requests.

    -syntax : 
        const api = axios.create({
            baseURL: 'https://api.example.com',
            headers: {
                'Content-Type': 'application/json',
                'Authorization': 'Bearer token'
            }
        });

        api.get('/endpoint')
            .then(response => {
                // handle success
            })
            .catch(error => {
                // handle error
            });

interceptors : are functions that are called before a request is sent or after a response is received. they allow you to modify the request or response before it is handled by the application. they are useful for adding authentication tokens, logging requests, and handling errors.

    -syntax : 
        api.interceptors.request.use(
            config => {
                // modify request config
                return config;
            },
            error => {
                // handle request error
                return Promise.reject(error);
            }
        );

        api.interceptors.response.use(
            response => {
                // modify response data
                return response;
            },
            error => {
                // handle response error
                return Promise.reject(error);
            }
        );

        example of axios instance with interceptors : 
            import axios from 'axios';

            const api = axios.create({
                baseURL: 'https://api.example.com',
                headers: {
                    'Content-Type': 'application/json',
                    'Authorization': 'Bearer token'
                }
            });

            api.interceptors.request.use(
                config => {
                    // modify request config
                    return config;
                },
                error => {
                    // handle request error
                    return Promise.reject(error);
                }
            );

            api.interceptors.response.use(
                response => {
                    // modify response data
                    return response;
                },
                error => {
                    // handle response error
                    return Promise.reject(error);
                }
            );

            export default api;


axois requst configuration : 
    -method : HTTP method to be used for the request. it can be GET, POST, PUT, DELETE, PATCH, etc.
    -url : URL of the API endpoint to which the request is to be sent.
    -headers : object containing any custom headers to be sent with the request.
    -params : object containing any query parameters to be sent with the request.
    -data : object containing any data to be sent with the request. it is used for POST, PUT, and PATCH requests.

            );
        };

    useref hook : is a hook provided by React that allows you to create a reference to a DOM element or a React component. it can be used to access the properties and methods of the referenced element or component.
    -syntax :
        import { useRef } from 'react';

        const Component = () => {
            const inputRef = useRef(null);

            const handleClick = () => {
                inputRef.current.focus();
            };

            return (
                <div>
                    <input ref={inputRef} type="text" />
                    <button onClick={handleClick}>Focus Input</button>
                </div>
            );
        };
